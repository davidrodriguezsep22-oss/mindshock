Política de privacidad

Esta página explica qué información procesa MindShock cuando una persona solicita una revisión comercial o contrata el Sprint de caso comercial B2B.

Responsable y contacto

MindShock. Para consultas, solicitudes relacionadas con tus datos o ejercicio de derechos, escribe a ventas@mindshock.app.

Información que podemos recibir

El formulario puede solicitar nombre, correo de trabajo, empresa, rango de clientes activos y una descripción de la propuesta u oportunidad que quieres reactivar. También puede registrar información técnica limitada —por ejemplo, identificadores de seguridad, agente del navegador o una representación hash de la IP— para prevenir abuso y aplicar límites de uso.

Material de proyectos

Si el servicio avanza, puedes compartir propuestas, presentaciones, transcripciones, notas u otro material propio o autorizado. No envíes contraseñas, datos completos de tarjetas, documentos de identidad ni información sensible que no sea necesaria para prestar el servicio.

Finalidades

  • Revisar si el proyecto encaja con el servicio y responder la solicitud.
  • Preparar el caso comercial, los mensajes y la revisión contratada.
  • Prevenir abuso, fraude o uso automatizado del formulario.
  • Gestionar soporte, pagos y comunicaciones directamente relacionadas con la solicitud.

Uso de inteligencia artificial

Cuando la función esté habilitada, una solicitud válida puede enviarse a la API de OpenAI para generar una vista previa o diagnóstico preliminar. Esa vista previa no sustituye la revisión humana ni constituye la entrega final. Según la política vigente de OpenAI para su API, los datos enviados a la API no se utilizan para entrenar modelos por defecto, salvo que el cliente de la API opte expresamente por compartirlos.

Proveedores tecnológicos

MindShock utiliza infraestructura de Supabase para recibir y almacenar solicitudes, y puede utilizar la API de OpenAI para funciones de asistencia editorial. Los pagos se realizan en páginas externas de Bold o PayPal; MindShock no solicita que introduzcas los datos completos de tu tarjeta dentro de este sitio.

Conservación y publicación

La información se conserva durante el tiempo necesario para atender la solicitud, prestar el servicio, mantener registros operativos razonables y cumplir obligaciones aplicables. El material de un cliente no se publica como caso público o testimonio sin autorización expresa.

Tus derechos

De acuerdo con las normas colombianas de protección de datos personales, cuando resulten aplicables puedes solicitar conocer, actualizar, rectificar o suprimir tus datos, así como revocar una autorización en los casos procedentes. Escríbenos a ventas@mindshock.app indicando tu solicitud y el correo utilizado en el formulario.

Actualizaciones

Podemos actualizar esta política si cambia el servicio o la forma en que tratamos la información. La versión publicada en esta dirección es la vigente.

Última actualización: 9 de agosto de 2026.

Referencia normativa general: Ley 1581 de 2012 y Decreto 1074 de 2015 sobre protección de datos personales en Colombia. Esta página describe el tratamiento operativo de MindShock y no sustituye asesoría jurídica.
