## 8. Regla de publicación
Antes de subir el caso a mindshock.app, confirmar que:
1. existe una transacción real;
2. el servicio fue materialmente entregado;
3. las afirmaciones están respaldadas por evidencia;
4. no se presenta una demostración como resultado de cliente;
5. existe autorización para cualquier elemento identificable o testimonial;
6. no se publican datos sensibles o confidenciales;
7. el texto no promete que todos los clientes obtendrán el mismo resultado.
