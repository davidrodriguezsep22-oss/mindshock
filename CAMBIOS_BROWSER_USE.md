# MindShock — mejoras tras prueba de comprador

Cambios aplicados al index.html:

- “Customer Evidence Readiness” pasa a español en la primera impresión.
- El 0–100 se presenta como indicador editorial orientativo, no como medición científica ni predicción de ventas/ROI.
- El autodiagnóstico gratuito deja de mostrar un 0–100 mecánico: ahora clasifica la etapa de forma cualitativa.
- Se añade una muestra ficticia integrada del Mapa con indicador, ángulo, comprador, objeción, evidencia faltante y veredicto.
- La sección de David se mueve antes de la oferta y ya no depende del enlace de LinkedIn para generar confianza.
- El formulario separa conceptualmente Proyecto / Comprador / Objeción mediante instrucciones claras.
- Se elimina una sección redundante de encaje para acortar la landing.
- Se reduce la repetición de las condiciones de inicio en el hero.
- El precio se encuadra como pago por una decisión documentada, no como producción barata de un case study.
- Se mantienen Bold, PayPal, Supabase, privacidad, términos y el precio COP 70.000 / USD 22.
