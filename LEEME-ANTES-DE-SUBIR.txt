CÓMO SUBIRLO A GITHUB
1. Descomprime el ZIP.
2. Entra al repositorio: davidrodriguezsep22-oss/mindshock
3. Sube estos archivos a la RAÍZ del repositorio, no dentro de una carpeta nueva.
4. Reemplaza los archivos existentes cuando GitHub lo solicite.
5. Haz el commit directamente en main si quieres publicarlo de inmediato.
6. NO borres CNAME: es el archivo que conserva mindshock.app.
7. Después del commit, abre https://mindshock.app y recarga la página.
